# Kantonswappen

Pro Kanton eine Datei mit dem Kantonskürzel als Namen: `BS.svg`, `GR.svg`, `ZH.svg` …
SVG wird bevorzugt, PNG (`BS.png`) geht auch. Fehlt die Datei, zeigt die Grafik einfach kein Wappen.

Darstellung: 32 px hoch hinter dem Titel (bei 1920×1080), Breite folgt dem Seitenverhältnis.
In der Referenz (SRF 2023) steht das Wappen auf weissem, rechteckigem Grund.
Die Dateien sollten diesen Grund schon enthalten.
